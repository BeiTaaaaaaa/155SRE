### 什么是进程

进程是一个系统中正在运行的程序，具有生命周期，是操作系统资源分配的基本单位

### 进程，线程，协程的区别有哪些

线程：是进程中的一个执行单位，也是操作系统中的能够进行运算调度的最小单位，负责当前进程中程序的执行

协程：是一种用户态的轻量级线程，不受操作系统内核管理，完全由程序控制，协程能够在执行过程中暂停并保存当前的执行状态，之后再从暂停的位置恢复执行，实现程序的异步执行

区别：

1. 进程和线程由内核采用抢占式调度，而协程采用的协作式调度

2. 进程适合需要完全隔离的任务，如运行多个独立程序；

   线程适合CPU密集型任务，可利用多核CPU并行处理（如数据计算）

   协程适合I/O密集型任务（如网络请求，数据库查询），在等待I/O时切换协程，避免线程阻塞，提升效率

3. 进程占用资源最多，线程其次，协程最少

4. 进程切换开销大，线程其次，协程极小

5. 进程的通信方式需IPC（管道，socket等），线程则是共享内存（需锁机制），而协程则是直接共享变量（无锁竞争）

### 进程的种类有哪些

1. 按功能与服务对象划分
   * 系统进程：由操作系统内核创建和管理，用于提供系统核心服务的进程
   * 用户进程：由用户启动的应用程序对应的进程，运行在用户态
2. 按进程状态划分
   * 运行态：进程正在 CPU 上执行指令，或处于就绪队列中等待 CPU 调度
   * 就绪态：进程已分配到除 CPU 外的所有资源，等待系统调度 CPU 时间片
   * 阻塞态：进程因等待某类事件（如 I/O 操作完成、信号量释放）而暂停执行，即使分配 CPU 也无法运行
   * 创建态：进程正在被创建，操作系统正在为其分配资源（如内存、PID），尚未进入就绪队列
   * 终止态：进程执行完毕或因错误终止，资源已被系统回收（如内存释放、PID 注销）
3. 按运行模式划分
   * 内核态进程：运行在操作系统内核空间，可直接访问所有硬件资源和内核数据结构，执行特权指令（如修改页表、关闭中断）
   * 用户态进程：运行在用户空间，只能访问自身地址空间和有限的系统资源，需通过 “系统调用” 切换到内核态才能请求高级服务
4. 按进程关系划分
   * 父进程：启动其他进程的进程，拥有对子进程的管理权限（如创建、终止子进程，获取子进程状态）
   * 子进程：由父进程通过系统调用（如`fork()`、`CreateProcess()`）创建的进程，继承父进程的部分资源（如环境变量、文件描述符）
5. 特殊类型进程
   * 守护进程：在后台运行的特殊用户进程，脱离终端控制，通常随系统启动并长期运行
   * 僵尸进程：子进程终止后，父进程未及时回收其资源（如 PID、退出状态），导致进程残留的状态信息保存在内核中
   * 孤儿进程：父进程先于子进程终止，子进程被操作系统 “收养”（通常由`init`进程或`systemd`进程接管）
   * 批处理进程：无需用户交互、按预设任务序列自动执行的进程（如定时任务`crontab`、数据备份脚本）

### 进程的通信方式有哪些

1. 基于数据传递的通信方式
   * 管道（Pipe）：操作系统在内存中创建的一个单向数据流通道，类似 “文件” 但只存在于内存中，通过文件描述符操作
   * 命名管道（Name Pipe/FIFO）：与管道类似，但通过文件系统中的特殊文件（FIFO 文件）标识，可用于无亲缘关系的进程
   * 消息队列（Message Queue）：内核维护的一个消息链表，进程可按 “类型” 发送 / 接收消息（数据块），类似 “邮箱”
   * 共享内存（Shared Memory）：多个进程将同一块物理内存映射到各自的虚拟地址空间，直接读写内存实现通信
2. 基于同步与互斥的通信方式
   * 信号量（Semaphore）：内核维护的一个整数变量，用于控制多个进程对共享资源的访问（本质是 “计数器”）
   * 互斥锁（Mutex）：特殊的信号量（值只能为 0 或 1），用于保证同一时间只有一个进程访问临界资源
   * 条件变量（Condition Variable）：配合互斥锁使用，允许进程在特定条件不满足时阻塞，条件满足时被唤醒
3. 基于信号的通信方式
   * 信号（Signal）：操作系统向进程发送的 “事件通知”（如错误、中断），进程可自定义处理函数
4. 网络协议，-based通信方式
   * 套接字（Socket）：基于 TCP/IP 或 UDP 协议的网络通信接口，支持不同主机或同一主机的进程通信
   * 远程过程调用（RPC,Remote Procedure Call）：允许一个进程（客户端）调用另一个进程（服务器）中的函数，屏蔽网络通信细节，类似本地函数调用
5. 其他特殊通信方式
   * 文件（File）：进程通过读写同一文件交换数据，适用于简单场景，但效率低（依赖磁盘 I/O），需手动处理同步
   * 信号量集（Semaphore Set）：一组信号量的集合，可同时操作多个信号量，减少系统调用次数

### 什么是僵尸进程

当子进程已经终止，但父进程尚未读取其退出状态时，子进程就会暂时保留在进程表中，成为僵尸进程

### 进程的状态有哪些

* 运行态：进程正在 CPU 上执行指令，或处于就绪队列中等待 CPU 调度
* 就绪态：进程已分配到除 CPU 外的所有资源，等待系统调度 CPU 时间片
* 阻塞态：进程因等待某类事件（如 I/O 操作完成、信号量释放）而暂停执行，即使分配 CPU 也无法运行
* 创建态：进程正在被创建，操作系统正在为其分配资源（如内存、PID），尚未进入就绪队列
* 终止态：进程执行完毕或因错误终止，资源已被系统回收（如内存释放、PID 注销）
* 僵尸状态：当一个子进程完成执行（终止）后，其内核数据结构（如进程控制块 PCB）不会立即被操作系统释放，而是暂时保留在进程表中，等待父进程通过系统调用（如`wait()`、`waitpid()`）读取其退出状态（如退出码、终止原因），此时，该子进程就处于僵尸状态



### 什么是守护进程

是运行在操作系统后台的一种特殊进程，通常独立于用户交互，以服务形式长期运行，负责执行特定任务（如网络服务、日志记录、系统监控等），其核心特点是脱离终端控制、在后台持续运行，是操作系统中许多基础服务的实现方式。
